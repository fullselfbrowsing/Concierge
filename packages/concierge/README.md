# @fullselfbrowsing/concierge

**Typed, consent-gated actions that let an AI agent operate your web app.**

Core package — catalog DSL, dispatcher, deduplication, bridge registry, consent kernel, matching, redaction.

No DOM. No framework. No vendor. Constructs on the server under Next App Router, Nuxt, and SvelteKit without environment guards.

> **Pre-alpha.** This package currently ships the design contract (types) only. The runtime is in progress.

Full documentation, design rationale, and the framework adapters live in the [repository README](https://github.com/fullselfbrowsing/concierge#readme).

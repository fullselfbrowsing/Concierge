<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| application values → canonicalizer | Untrusted object graphs may contain executable properties, aliases, traps, invalid Unicode, or unstable state. |
| delivery adapter → owned callback | Receipts and attestations are caller-controlled claims until recomputed and cross-bound. |
| capability metadata → consent grade | A declared ability to attest is not evidence that attestation occurred. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-02 | Elevation of privilege | asynchronous presentation and delivery ownership | mitigate | Review success or a partially completed presentation cannot arm: presenter/digest awaits re-check generation and response ownership, and only matching completed delivery advances. |
| T-08-04 | Elevation of privilege | achieved consent grade | mitigate | Declared and actual capabilities remain ceilings; only verified occurrence evidence derives `attested`. |
| T-08-05 | Tampering / Spoofing | canonical readback and receipt | mitigate | Descriptor-first strict JCS/UTF-8, alias/cycle rejection, retained byte copy, and a fresh digest require exact `alg`, canonicalization, byte, and hash agreement. |
| T-08-06 | Spoofing | human attestation | mitigate | Bind confirmed act to genuine user turn, generation, response, receipt, and report hash. |
| T-08-10 | Information disclosure / Tampering | hostile readback objects and async callbacks | mitigate | Descriptor-first reads, fixed closed failures, defensive copies, no caught-value echo, and post-await ownership checks contain hostile values and late callbacks. |
| T-08-SC | Tampering | package supply chain | mitigate | No package install is permitted; release verification proves lockfile byte identity. |
</threat_model>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Transport batch callback → Session queue | Repeated, malformed, concurrent, or already-aborted occurrences enter core control flow. |
| Session epoch → dispatcher context | Work captured under an old action allowlist must not execute as if it belongs to a new one. |
| Dispatcher rows → transport.respond | A thrown response has ambiguous acceptance and must neither halt the queue nor trigger retry. |
| Transport envelope → handler InvocationMeta | Turn/delivery evidence must pass unchanged so Session cannot spoof consent inputs. |
| Hostile ToolBatch getters → Phase 6 total snapshot | An eager Session spread/read could throw before dispatchBatch and bypass its guarded total-row behavior. |

## STRIDE Threat Register

| Threat ID | Severity | Category | Component | Disposition | Mitigation and verification |
|-----------|----------|----------|-----------|-------------|-----------------------------|
| T-07-01 | high | Elevation of privilege / Tampering | context epoch and old work | mitigate | Capture provisional/confirmed context+epoch at arrival, keep the pump paused through publication, abort active/queued/held older scopes before publication, and distinguish same-catalog updates; C10-C14 and J07-J10 are blocking. |
| T-07-02 | high | Tampering / Repudiation | FIFO, dispatcher occurrence, responses | mitigate | One explicit pump, one dispatch per accepted occurrence, one attempt per row, no retry, and immutable stub histories; J01-J05 are blocking. |

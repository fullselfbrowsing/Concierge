`createConcierge` reaches the single-instance guard.

the work at runtime, so a type test is the only thing that can tell a `readonly` build from a
mutable one. And the spelling matters: `readonly` property modifiers do not affect assignability, so
an `Assignable` pin stays green with every modifier deleted. `catalog.test-d.ts:300-301` already
argues exactly this one level down for `CatalogEntry`; this file applies it to `EmittedTool`.

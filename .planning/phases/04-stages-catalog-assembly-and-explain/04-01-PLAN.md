<objective>
Make the type contract carry Phase 4's three additions before any runtime exists to satisfy them:
`Explanation` / `StageExplanation` as named exported interfaces, `Concierge.explain` as a member,
and `EmittedTool`'s four fields as `readonly`.

Purpose: two of these are free today and breaking later. `isolatedDeclarations` forbids an inline
anonymous return type on `Concierge.explain`, so `Explanation` has to be named regardless — and
nothing constructs an `EmittedTool` yet, which is the only window in which tightening it costs
nothing. `types.ts:1299-1311` already records the governing argument in this very file: a `readonly`
that does not go all the way down is *worse than none*, "because a reader stopped looking", and
`ReadonlyArray<EmittedTool>` protects the array while leaving `catalogFor(ctx)[0].name = "evil"`
compiling clean (measured).

Output: a `types.ts` that Phase 4's runtime can be written against, with no runtime change at all —
nothing in `src/` implements `Concierge` yet, so this plan cannot break a build.
</objective>

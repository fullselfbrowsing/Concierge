<objective>
Grow the public barrel by ten types and four values, and move the export-surface pin in lockstep
across the four files that carry it.

Purpose: `verbatimModuleSyntax` enforcement is **one-directional**. A type written into the value
block is TS1205 and nobody can miss it. A value moved the other way — out of the value block and
into `export type { … }` — is silently legal: `tsc -p tsconfig.test-d.json` exits 0, the emit build
exits 0, and `dist/index.js` quietly loses the runtime binding. `attw` and `publint` are BLIND to
it: mutant P8 measured both reporting "No problems found" with exit 0 on a build whose
`dist/index.js` had lost an export. Only the typecheck and the artifact cases catch it, which is why
all four files move together.

Output: the barrel, and its three guards, all agreeing.
</objective>

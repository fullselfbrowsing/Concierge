<objective>
Land `defineAction` and the CAT-07 literal-description guard — the one requirement in this
phase that runtime cannot satisfy, because an i18n-derived description is byte-identical at
runtime to a hand-written one.

Purpose: tool-description poisoning is the attack CAT-07 exists to block, and the guard the
literature reaches for (`string extends D`) **admits it**. RESEARCH measured that
`` `Tenant ${tenant} filter.` `` infers the *pattern type* `` `Tenant ${string} filter.` ``,
not `string`, so `string extends <pattern>` is false and the naive predicate passes its own
tests while leaving its centre open. This plan lands the six-branch predicate that closes
every `${string}` hole position, and makes the rejection branch itself the error sentence so
`tsc` prints it verbatim in the terse output CI actually sees (DX-03).

Output: `src/define-action.ts`, `test-d/description-literal.test-d.ts`, and the swap of
`test-d/actions.test-d.ts`'s Phase-1 placeholder for the real function.
</objective>

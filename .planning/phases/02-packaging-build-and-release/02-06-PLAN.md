<objective>
THE HINGE. Add the first executable code this package has ever contained.

Purpose: `CONTRACT_VERSION` and `assertSingleInstance` are the mechanism behind PKG-04 —
"two adapters resolving core independently share one core instance, and a version mismatch fails
loudly rather than silently splitting the bridge registry, the dedup window, and the consent
kernel." Everything before this plan was toolchain; everything after consumes it. PKG-04 is the
test that it works and PKG-05 is the measurement it must not break, which is why plan 02-05 landed
first and recorded a baseline.

The central finding this plan exists to honour: **`sideEffects: false` and a module-scope registry
are mutually exclusive.** Measured with rolldown 1.2.0 — a module-evaluation-time `globalThis`
registration is deleted from a consumer bundle *even when the consumer imports `CONTRACT_VERSION`
itself*, because the constant is inlined and the module's evaluation is then dropped entirely. A
module-scope detector is present under `node dist/index.js` and absent from every React or Svelte
app, which is the only place two adapters can collide. It would test green and do nothing.

The resolution is not to relax `sideEffects`. It is to put the check on a **reachable code path**.
Measured (`02-RESEARCH.md:205-210`): a consumer bundle is **63 B** when `assertSingleInstance` is
uncalled and **587 B** when it is called — i.e. the registry code itself contributes **0 bytes when
uncalled**. Use the 63 / 587 pair verbatim; plan 02-07 records the same pair, and plan 02-12
compares the two SUMMARYs.
Output: `src/contract.ts`, two new value exports, an export surface of 45, and a re-verified
PKG-05 measurement.
</objective>

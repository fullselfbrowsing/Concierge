<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| source tree → packed tarball | `files` decides what escapes into the published artifact; the in-build gate cannot see this boundary |
| packed tarball → consumer resolver | `exports`, `types` and `type` decide what a consumer's bundler and compiler resolve |
| repository → published source text | Publishing `src/` and shipping `sourcesContent` makes unexported declarations readable |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-10 | Tampering | `attw: true` in `tsdown.config.ts` | mitigate | Configure `attw: { level: "error", profile: "esm-only" }`. A silently-passing gate is a security failure, not a cosmetic one: it lets a broken artifact reach consumers while CI is green. Acceptance criteria assert `attw: true` does not appear. Plan 02-04 proves the gate fires. |
| T-02-11 | Tampering | `attw`'s default profile | mitigate | Pass `--profile esm-only` in both the build config and the standalone script. The "obvious fix" for the default-profile failure is adding a CJS build, which reverses the locked ESM-only decision and reintroduces the dual-package hazard that the one-instance invariant exists to prevent. |
| T-02-12 | Information Disclosure | `files` including `src` | accept | `serverChallengeBrand` and `ConsentAckBase` ship as readable text. They already do, inside `dist/index.js.map`'s 57 kB `sourcesContent`. MIT public library; the design rationale in `types.ts` is not a secret. Recorded as a decision in the SUMMARY rather than left implicit. |
| T-02-13 | Information Disclosure | `files` letting test or script sources escape | mitigate | The packed file list is enumerated with `tar -tzf` and asserted to contain no `test-d`, `scripts`, `node_modules` or `tsconfig` path. |
| T-02-14 | Tampering | a manifest defect visible only after packing | mitigate | `check:artifact` packs first. Measured defect D5 (`files` omitting `dist`) is caught **only** here; plan 02-04 mutant P2 proves it. |
| T-02-SC | Tampering | npm/pnpm installs | accept | This plan installs nothing new. All packages were installed and audited in plan 02-01. |

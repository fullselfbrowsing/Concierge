<objective>
Close CR-01 and WR-01: **the consent-critical artifacts are writable, so every guarantee this
phase established at construction time is defeatable by plain assignment afterwards.**

CR-01 is the blocker. TypeScript computes the *write* type of a property on a union-typed value as
the union of the branches' write types, so `ack.grade = "attested"` compiles on any `ConsentAck`
with no cast, no `any`, and no suppression. The compiler then narrows on the forged discriminant
and hands the consumer `ack.readbackHash` typed `string` when the property is absent at runtime —
at exactly the narrowing idiom `consent.test-d.ts`'s own `narrowsThroughTheUnion` teaches as
correct. That is not merely a missing block; it is the compiler issuing a **false guarantee** to a
hash comparison. `types.ts:421` promises "structurally frozen at arm time" in prose, in the one file
whose stated thesis (`types.ts:454`) is that prose has never once stopped a defect from being built.

WR-01 is the same defect class on four more surfaces, and it must land in the same plan rather than
after it: closing the class on `ConsentAck` while leaving `DeliveryReport`, `ReadbackReceipt`, and
`TransportCapabilities` open would be a partial fix that reads as a complete one. `TurnIdentityProvenance`
exists so the kernel can tell a forgeable id from an attested one; a value that can be upgraded in
place carries no such distinction. `Transport.capabilities` at `:1010` is already `readonly`, which
reads as protection and is not — the `readonly` stops rebinding the reference and does nothing about
the members.

**This is the last free moment.** `.planning/PROJECT.md`: "Nothing publishes until v0.1 completes, so
Phase 1 type decisions remain amendable through Phase 8 at zero cost." Adding `readonly` after publish
IS a breaking change for any consumer that mutates. Phase 1's own goal is *"the remaining defects that
would become breaking changes after publish are closed"* — this is exactly that, and it was missed
because the phase's 19-mutation battery tests construction and never tested mutation.

Purpose: make the project's own recorded Established Pattern (`01-CONTEXT.md:600` — "`Object.freeze` +
`Readonly<>` for anything the agent or app must not mutate") true of the artifacts it most obviously
governs.
Output: `readonly` on **20** members across five declarations (5 on `ConsentAckBase`, 4 across the two
`ConsentAck` branches, 3 on `DeliveryReport`, 4 on `ReadbackReceipt`, 4 on `TransportCapabilities`),
and the named guards the suite lacks.

**Serial phase.** Plan 10 of the gap-closure sequence. `packages/concierge/src/types.ts` is ONE file
and no other plan may edit or transiently mutate it in this wave. Do not parallelize.

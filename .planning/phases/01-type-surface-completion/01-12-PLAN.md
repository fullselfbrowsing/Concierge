handler-context construction — Phase 6 cannot build a context for a non-gated action without either
this fix or a cast into the security-critical path.

**This is the least dangerous finding in the set and it is still worth closing here.** Adding
`| undefined` widens the write type and leaves the read type unchanged under EOPT, so it is not
breaking to add later — which is exactly why the review graded it a warning rather than a blocker.
It lands now because the cost is one modifier per member while the file is open, and because the
alternative is that every consumer meets the friction and reaches for `as`.

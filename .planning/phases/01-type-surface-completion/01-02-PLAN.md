      it forces every mapper to be updated rather than silently defaulting. Note that
      `batch_aborted` deliberately collapses into `aborted`, and that `grade_unavailable` is a
      runtime code for capability degradation after reconnect only, since CAT-04 throws at build time.
    - On `ActionResult.message`: state the policy verbatim in substance — **`message` is a
      best-effort human-facing sentence and is never a consent artifact** — and state the
      `MESSAGE_MAX_CHARS` bound, noting that Phase 6 (SEC-06) enforces it at the dispatcher boundary
      and that the type system cannot express a length constraint, which is why this is a constant

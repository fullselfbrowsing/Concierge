<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| transport metadata → session | Caller-owned descriptors and capability claims cross into session construction. |
| dispatch result → application sink | Failure details leave the execution core for user-facing presentation. |
| application sink → agent response | Untrusted completion/interruption controls whether results may be released. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Spoofing / Elevation of privilege | actual turn-provenance gate | mitigate | Human-attested user-turn provenance and non-forgeable actual capability are validated before effects; agent-forgeable and look-alike profiles fail closed. |
| T-08-04 | Elevation of privilege | capability versus achieved proof | mitigate | Actual capability must dominate the declaration but remains only a ceiling; it is never copied into occurrence evidence or treated as achieved grade. |
| T-08-08 | Information disclosure / Tampering | app-authored failed-batch outcome | mitigate | Minimal frozen rows exclude model/argument data, one completed sink call precedes every response, and throw/reject/interruption cause no release or retry. |
| T-08-10 | Information disclosure / Tampering | hostile capability and outcome callbacks | mitigate | Descriptor-aware snapshots, fixed START/outcome diagnostics, malformed-report rejection, and no caught-value echo contain hostile objects and callbacks. |
| T-08-SC | Tampering | package supply chain | mitigate | No package install is permitted; final release gate verifies lockfile identity. |
</threat_model>
